Claude Gmail

个人自用应用 · Personal-use app

这是什么

Claude Gmail 是 GitHub 用户 franzwei-lab 自己使用的小工具。它让本人电脑上的 Claude Code 通过开源的 workspace-mcp 访问本人自己的 Gmail 邮箱，用来搜索、阅读、整理和发送邮件。

它不对外提供服务，没有网站后台，也不收集任何其他人的数据。

What is this

Claude Gmail is a small personal tool used only by its owner (GitHub user franzwei-lab). It lets Claude Code on the owner's own computer access the owner's own Gmail account through the open-source workspace-mcp server, to search, read, organize and send email.

It is not offered to the public, has no hosted backend, and does not collect anyone else's data.
