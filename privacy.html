隐私政策 · Privacy Policy

Claude Gmail · 更新于 2026-10-18 · Last updated 2026-10-18

中文

Claude Gmail 是个人自用应用，唯一的用户是应用所有者本人。

  • 访问哪些数据：经本人授权后，读取、整理和发送本人 Gmail 邮箱中的邮件、标签和过滤器。
  • 数据存在哪里：授权令牌只保存在本人电脑上。没有任何服务器存储邮件或令牌。
  • 数据去向：邮件数据只在本人电脑与 Google API 之间传输。本人让 Claude 处理某封邮件时，这些内容会作为对话的一部分发送给 Claude（Anthropic）。
  • 不出售、不共享：不向任何第三方出售或共享数据，不用于广告。
  • 撤销授权：可随时在 Google 账号权限页面撤销本应用的访问权限。
  • Google 政策：本应用对通过 Google API 获得的信息的使用，遵守 Google API 服务用户数据政策，包括其中的"有限使用"要求。
  • 联系方式：请在本网站的 GitHub 仓库提交 issue。

English

Claude Gmail is a personal-use app. Its only user is the app owner.

  • Data accessed: with the owner's consent, the owner's own Gmail messages, labels and filters, to read, organize and send email.
  • Storage: OAuth tokens are stored only on the owner's computer. No server stores email or tokens.
  • Data flow: email data moves only between the owner's computer and Google APIs. When the owner asks Claude to work with a message, that content is sent to Claude (Anthropic) as part of the conversation.
  • No selling or sharing: data is never sold, shared with third parties, or used for advertising.
  • Revoking access: access can be revoked at any time on the Google Account permissions page.
  • Google policy: use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
  • Contact: open an issue in this site's GitHub repository.
